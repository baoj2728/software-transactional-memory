# Software Transactional Memory
Dylan Bao (jiayuanb) and Samuel Zhang (samuelz2)

C++ Software Transactional Memory Runtime

1. Summary
We plan to implement a software transactional memory (STM) runtime in C++ that supports atomic transactions across multiple shared memory locations on multicore CPUs. We will evaluate its correctness and performance against traditional synchronization mechanisms, such as coarse-grained and fine-grained locking, and explore optimizations to improve scalability under different levels of contention.
